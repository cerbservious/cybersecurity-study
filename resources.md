# Resources (all free)

## CC exam prep
- Official CC exam outline (isc2.org) — the syllabus; everything maps back to this
- Free full CC video course on YouTube — search "ISC2 CC free course 2026" (ignore stale free-voucher claims in descriptions)
- [CertCrush](https://www.certcrush.app) — free CC lessons, practice questions, flashcards, mock exams per domain
- Udemy CC practice-exam set (6 tests / 900 questions) — free via coupon code when available

## Hands-on labs
- [TryHackMe](https://tryhackme.com) free tier — Pre Security path for networking + Linux basics, then intro-to-SOC rooms

## Networking depth (Domain 4)
- Professor Messer's free Network+ series (YouTube)
- Cisco "Introduction to Cybersecurity" (free, Cisco Skills for All)

## Reference
- [NIST Cybersecurity Framework 2.0](https://www.nist.gov/cyberframework) — free; the GRC bible
- [MITRE ATT&CK](https://attack.mitre.org) — free; threat frameworks at concept level
